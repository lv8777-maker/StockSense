# Maverick Loyalty App - Customer Process Flow

## 📋 Complete Customer Journey Guide

---

## 🎯 Overview

The Maverick Loyalty App is a digital rewards program where customers earn points through purchases and redeem them for exclusive rewards. Here's how the entire system works from start to finish.

---

## 1️⃣ GETTING STARTED

### **Step 1: Access the App**
- Customer visits the Maverick Loyalty web app
- Landing page displays tier benefits and signup options

### **Step 2: Choose Registration Method**

**Option A: Phone Number Registration (South African Numbers)**
1. Click "Continue with Phone (SA)"
2. Enter South African phone number (format: +27 or 0XX XXX XXXX)
3. Check "I'm a new customer" (if first time)
4. Enter first name and last name
5. **Select current telecom plan** from dropdown
6. Receive instant welcome points based on plan:
   - Essential/Core: 100 points → Starter Tier
   - Plus/Prime: 200 points → Explorer Tier
   - Deluxe/Elite: 300 points → Champion Tier
   - Bronze/Silver/Gold/Platinum: 500 points → Elite Tier

**Option B: Email Registration**
1. Click "Sign Up with Email"
2. Enter email address and create password
3. Enter first name and last name
4. **Select current telecom plan** from dropdown
5. Receive same welcome points based on plan
6. Account created with instant tier assignment

### **Step 3: First Login**
- User is redirected to dashboard
- Welcome points already credited
- Current tier displayed prominently

---

## 2️⃣ EARNING POINTS

Customers earn points through **three main methods**:

### **Method 1: Receipt Upload (Automated) ⭐ NEW**

**Process:**
1. Click **"Submit Receipt"** from navigation menu
2. Upload receipt image (photo or scan)
   - Supported formats: JPEG, PNG, WebP
   - Maximum size: 10MB
3. System automatically processes receipt with OCR
4. Points calculated and awarded instantly

**Point Awards:**

📱 **Airtime Purchases**
- Formula: 1 point per R1 spent
- Minimum: R100
- Example: R250 airtime = 250 points

🎧 **Accessory Purchases**
- R500-R999 = 100 points
- R1,000-R1,999 = 250 points
- R2,000+ = 500 points

📶 **Plan Subscriptions** (detected on receipt)
- Essential/Core Plans = 100 points
- Plus/Prime Plans = 200 points
- Deluxe/Elite Plans = 300 points
- Premium Tier Plans = 500 points

**What Happens Next:**
- Points credited immediately to account
- Transaction appears in purchase history
- Success notification shows points earned
- Receipt saved in upload history

### **Method 2: Manual Purchase Entry**
1. Navigate to transaction simulation
2. Enter purchase details manually
3. System calculates points based on purchase type
4. Points credited to account

### **Method 3: Special Offers & Bonuses**
1. Check "Notifications" for personalized offers
2. Complete offer requirements (e.g., "Spend R500 get 2x points")
3. Bonus points automatically applied

---

## 3️⃣ CHECKING BALANCE & ACTIVITY

### **Dashboard Overview**
Customer can view:
- **Total Points Balance** - displayed prominently in yellow badge
- **Current Tier Status** - Starter, Explorer, Champion, or Elite
- **Points Earned This Month** - monthly summary
- **Recent Activity** - last 5 transactions with point details

### **Transaction History**
1. Click "History" in navigation
2. View complete transaction log:
   - Date and time of each transaction
   - Purchase description
   - Points earned/spent
   - Running balance
3. Filter by date range or transaction type

### **Receipt Upload History**
1. Navigate to "Submit Receipt" page
2. Scroll to "Upload History" section
3. View all uploaded receipts:
   - Processing status (completed/processing/failed)
   - Detected purchase type
   - Amount recognized
   - Points awarded
   - View original receipt image

---

## 4️⃣ REDEEMING REWARDS

### **Step 1: Browse Rewards Catalog**
1. Click **"Rewards"** from navigation menu
2. Filter by category:
   - Food & Drinks
   - Merchandise
   - Experiences
   - Discounts
3. View available points balance at top

### **Step 2: Select Reward**
1. Browse rewards with clear point costs displayed
2. Click on desired reward to see details:
   - Description
   - Point cost
   - Availability status
   - Terms and conditions

### **Step 3: Claim Reward**
1. Click "Claim Reward" button
2. Confirm redemption in dialog box
3. System verifies sufficient points
4. Points deducted automatically

### **Step 4: Receive Confirmation**
1. Unique redemption code generated (e.g., RDM-A1B2C3D4)
2. Success notification displayed
3. Email confirmation sent with:
   - Redemption code
   - Reward details
   - Expiration date (30 days)
   - Redemption instructions

### **Step 5: Use Reward**
1. Present redemption code at partner location
2. Partner validates code
3. Reward marked as "Used" in system
4. Customer receives benefit

---

## 5️⃣ TIER PROGRESSION

### **How Tiers Work**

**Tier Levels & Requirements:**
- 🥉 **Starter Tier** - 0-499 points
- 🧭 **Explorer Tier** - 500-1,499 points
- 🏆 **Champion Tier** - 1,500-2,999 points
- 👑 **Elite Tier** - 3,000+ points

### **Tier Benefits**

**Starter Tier:**
- Basic rewards access
- Monthly newsletters
- Essential support

**Explorer Tier:**
- Enhanced rewards
- Priority customer service
- Exclusive monthly offers
- Data rollover

**Champion Tier:**
- Premium rewards catalog
- VIP customer service
- Free device upgrades
- International roaming discounts

**Elite Tier:**
- Platinum-level rewards
- Personal account manager
- Concierge services
- Exclusive event access

### **Automatic Tier Upgrades**
1. System tracks cumulative points earned
2. When point threshold reached, automatic upgrade
3. Notification sent about new tier
4. New benefits activated immediately
5. Dashboard updates to show new tier status

---

## 6️⃣ PROFILE MANAGEMENT

### **Update Profile**
1. Click "Profile" in navigation
2. Edit personal information:
   - Name
   - Email address
   - Phone number
   - Communication preferences
3. Changes saved automatically

### **Notification Preferences**
1. Go to Profile settings
2. Toggle preferences:
   - Email notifications (ON/OFF)
   - Push notifications (ON/OFF)
   - Marketing messages (ON/OFF)
3. Settings applied immediately

### **Plan Upgrades**
1. Navigate to Profile
2. Click "Upgrade Plan"
3. Select new plan from dropdown
4. Confirm upgrade
5. Receive bonus points for upgrade:
   - Higher tier plan = more bonus points
   - Points awarded based on plan tier difference

### **Account Deregistration**
1. Option available on landing page footer
2. Click "Deregister/Unsubscribe"
3. Confirm account removal
4. Phone number removed from system
5. Account deactivated (points preserved for 90 days)

---

## 7️⃣ NOTIFICATIONS & OFFERS

### **Checking Notifications**
1. Click bell icon or "Notifications" menu
2. View all system notifications:
   - Point awards
   - Tier upgrades
   - Special offers
   - Reward expirations
3. Mark as read individually
4. Recent notifications appear first

### **Personalized Offers**
1. System analyzes customer purchase patterns
2. Targeted offers generated automatically:
   - Double points on specific purchases
   - Bonus points for achieving milestones
   - Exclusive discounts for tier level
3. Notifications sent when new offer available
4. Time-limited offers show countdown

## 🛡️ SECURITY & PRIVACY

**Data Protection:**
- Secure session-based authentication
- Password encryption for email users
- HTTP-only cookies prevent XSS attacks
- Receipt images stored securely
- Personal data never shared with third parties

**Point Security:**
- All transactions logged with timestamps
- Redemption codes expire after 30 days
- Points cannot be transferred between accounts
- Audit trail for all point movements
