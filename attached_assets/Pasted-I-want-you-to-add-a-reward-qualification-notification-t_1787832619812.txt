1. Capture before/after balance and persist "newly qualified" rewards
This assumes POST /api/receipts/upload awards points correctly via a single call to storage.createTransaction(...) (points-awarding is already correct as of 2026-08-27 — do not add or modify any point-crediting logic beyond what's described below).

In POST /api/receipts/upload, before the existing storage.createTransaction(...) call:

Fetch the user's current balance via storage.getUser(userId) — this route doesn't currently fetch the user first, unlike the invoice-upload route, so add this call.
After storage.createTransaction(...):

Re-fetch the user via storage.getUser(userId) to get the actual post-award balance.
Fetch active rewards via storage.getActiveRewards().
A reward is newly qualified if balanceBefore < reward.pointsCost and balanceAfter >= reward.pointsCost. If more than one reward newly qualifies, treat all of them as newly qualified — not just the cheapest.
For each newly-qualified reward, insert a row into a new table (see schema below) recording that this user newly qualified for this reward, tied to the transaction that caused it. Do this instead of only returning it in the upload response, because — per the note above — the user does not get navigated to the Dashboard after upload, so the response payload alone would never reach the surface where the owner wants it shown.
New table — add to shared/schema.ts, following the existing style (varchar UUID PK via gen_random_uuid(), FK references, createInsertSchema for the insert type):

export const rewardNotifications = pgTable("reward_notifications", {
  id: varchar("id").primaryKey().default(sql`gen_random_uuid()`),
  userId: varchar("user_id").notNull().references(() => users.id),
  rewardId: varchar("reward_id").notNull().references(() => rewards.id),
  sourceTransactionId: varchar("source_transaction_id").references(() => transactions.id),
  status: varchar("status").default('pending'), // pending, redeemed, dismissed
  createdAt: timestamp("created_at").defaultNow(),
  resolvedAt: timestamp("resolved_at"),
});

export const insertRewardNotificationSchema = createInsertSchema(rewardNotifications).omit({
  id: true,
  createdAt: true,
  resolvedAt: true,
});
